# ⚽ Premier League Match Predictor

The **Premier League Match Predictor** is a full-stack web application where users can predict outcomes of Premier League fixtures. The app allows users to register, log in, submit predictions, and view leaderboards. Predictions are compared to actual results once matches are completed.

---

## 🚀 Features
- User authentication (JWT-based login/register)
- Browse upcoming Premier League fixtures
- Submit match predictions (scoreline or winner)
- Store predictions in a database
- View personal prediction history
- Leaderboard to rank users by accuracy (optional feature)
- RESTful API integration between backend and frontend

---

## 🛠️ Tech Stack
- **Frontend:** React.js, Context API, Fetch/Axios
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL (with Prisma ORM or Sequelize)
- **Authentication:** JSON Web Tokens (JWT)
- **ML** Premier League Data used from https://football-data.co.uk/
